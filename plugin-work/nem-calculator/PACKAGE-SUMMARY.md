# Package Summary

## Included

- Main WordPress plugin bootstrap
- Frontend calculator UI, styles, and JavaScript
- Admin settings page
- Dashboard and leads management screens
- Domestic Tariff A calculation engine
- Core product documentation

## Removed From Production Package

- Public verification pages
- Standalone test HTML files
- Debug-only diagnostic scripts
- Internal QA and troubleshooting artifacts
- Test shortcode registration

## Release Scope

- Residential Domestic Tariff A calculator
- Supported locations in Johor and Melaka
- Payment methods limited to Cash, Loan, and Credit Installment
