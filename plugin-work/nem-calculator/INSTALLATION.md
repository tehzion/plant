# Installation

## WordPress Admin Upload

1. Zip the `nem-calculator` folder if needed.
2. In WordPress admin, go to **Plugins > Add New > Upload Plugin**.
3. Upload the ZIP and click **Install Now**.
4. Activate the plugin.

## Manual Upload

1. Copy the `nem-calculator` folder into `/wp-content/plugins/`.
2. Activate **Solana Tec Smart Solar Calculator** from the Plugins screen.

## After Activation

1. Visit **Solana Tec > Settings**.
2. Review branding colors.
3. Enable lead capture if needed.
4. Configure the optional CTA button.
5. Add `[nem_calculator]` to your target page.

## Notes

- The plugin creates the `wp_nem_calculations` table on activation.
- This release is intended for Domestic Tariff A use only.
