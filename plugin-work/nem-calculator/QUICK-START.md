# Quick Start

## Launch Checklist

1. Install and activate the plugin.
2. Create a page and add `[nem_calculator]`.
3. Open **Solana Tec > Settings** and confirm:
   - Colors
   - Lead capture toggle
   - CTA settings
4. Visit the page and run one calculation with:
   - A valid monthly bill
   - One supported location
   - One payment method
   - A voltage level

## Supported Scope

- Domestic Tariff A only
- Johor and Melaka locations only
- Payment methods: Cash, Loan, Credit Installment

## Recommended Smoke Test

- Submit a calculation and confirm the results summary appears.
- Confirm the comparison table loads without JavaScript errors.
- Confirm charts render when Chart.js is available.
- Confirm optional lead data appears in **Solana Tec > Leads** when provided.
